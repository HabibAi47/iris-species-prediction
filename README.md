# Iris Flower Classification

A machine learning project that classifies iris flowers into three species (Setosa, Versicolor, Virginica) based on their measurements.

## Dataset
This project uses the classic **Iris dataset**, which contains 150 samples with these features:
- Sepal length
- Sepal width
- Petal length
- Petal width

Target classes: **Iris-setosa, Iris-versicolor, Iris-virginica**

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load and explore the dataset
2. Visualize the data
3. Split data into training and testing sets
4. Train the model
5. Evaluate the model's accuracy
6. Predict the species of new flowers
